# Minecraft Mod Loader

## Использование

1. Запустите Minecraft
2. Запустите `test.cmd`
3. Нажмите `1` — поиск процесса Minecraft
4. Нажмите `1` ещё раз — загрузка мода
5. В игре нажмите **Right Shift** — открыть/закрыть ClickGui

## Требования

- Windows
- Java JDK 8+ (в PATH)
- Запущенный Minecraft
